プライバシーポリシー

制定日: 2026年10月1日

1. 対象

このポリシーは、個人用ツール「my-local-mcp」（以下「本ツール」）に適用されます。本ツールは開発者本人だけが、自分の Google アカウントに対して使うものです。第三者への提供は行っていません。

2. アクセスするデータ

  • Gmail: メッセージと設定の閲覧（gmail.readonly）。送信・削除・変更は行いません。
  • Google ドライブ: すべてのファイルの閲覧（drive.readonly）と、本ツールが作成したファイルだけの作成・編集（drive.file）。

3. データの使い方

  • 本ツールは開発者本人の Mac 上で動作し、本人が AI アシスタントに依頼したときに限って、必要なメールやファイルを取得します。
  • 取得した内容は、本人の依頼に応えるために、本人が利用する AI アシスタント（Anthropic 社の Claude）に会話の一部として渡されます。
  • 本ツールは独自のサーバーを持たず、取得したデータを本ツールとして保存・蓄積しません。
  • データを販売したり、広告に使ったり、上記以外の第三者に提供したりすることはありません。

4. 認証情報の保管

OAuth の認証情報は、開発者本人の Mac のキーチェーンにのみ保存されます。

5. Google API サービスのユーザーデータに関するポリシー

本ツールによる Google API から受け取った情報の使用および他のアプリへの転送は、Google API Services User Data Policy（限定使用の要件を含む）に従います。

6. アクセスの取り消し

Google アカウントのサードパーティ アクセスから、いつでも本ツールのアクセスを取り消せます。

7. お問い合わせ

このページを公開している GitHub リポジトリの Issues からご連絡ください。

Privacy Policy

Effective date: October 1, 2026

Scope. This policy applies to "my-local-mcp", a personal tool used only by its developer with the developer's own Google account. It is not offered to anyone else.

Data accessed. Gmail messages and settings (read-only, gmail.readonly); all Google Drive files (read-only, drive.readonly); and files created by this tool (create/edit, drive.file).

How data is used. The tool runs on the developer's Mac and fetches emails or files only when the developer asks the AI assistant to do so. The fetched content is passed, as part of the conversation, to the AI assistant the developer uses (Claude by Anthropic) to fulfill that request. The tool has no server of its own and does not store fetched data. Data is never sold, used for advertising, or shared with any other third party.

Credentials. OAuth credentials are stored only in the macOS Keychain on the developer's Mac.

Google API Services User Data Policy. The use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access. Access can be revoked at any time at Google Account third-party access.

Contact. Please use the Issues of this GitHub repository.
